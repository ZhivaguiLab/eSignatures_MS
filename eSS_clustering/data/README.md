# data/

The SBS inputs and COSMIC references used for the manuscript are tracked in git,
so the SBS pipeline runs without adding anything. DBS and ID inputs are not
included; copy or symlink them into `input/DBS/` and `input/ID/` before running
those types. `input_cleaned/` is generated by preprocessing and is not tracked.

```
data/
  input/SBS/        ← tracked: 5 unfiltered count files, one per species (listed below)
  input/DBS/        ← not included
  input/ID/         ← not included
  references/       ← tracked: COSMIC v3.6 SBS, DBS, ID profiles, and
                      context_distributions/ (genome/exome trinucleotide
                      counts for the optional opportunity normalization)
  input_cleaned/    ← generated by preprocessing, not tracked
```

### SBS inputs in this repository

`input/SBS/` holds every profile **before** the mutation-count filter. The
filter, the name-based exclusions and the normalized profiles are all produced
by preprocessing (`config/preprocessing.yaml`), so the files here are the
starting point for the whole SBS analysis.

| File | Profiles | Default cutoff (`min_mutations`) | Clustered | Source |
|------|---------:|-------------------------:|----------:|--------|
| `unfiltered_mouse_SBS96.txt` | 723 | 307 | 361 (371 pass, then 10 MEF excluded by name) | `combined_mouse.txt` (`mouse_ind_stan.txt` + `mouse_ATC_samples.txt`) |
| `unfiltered_human_SBS96.txt` | 486 | 307 | 194 | `human_ind_stan_nhu.txt` |
| `unfiltered_celegans_SBS96.txt` | 245 | 307 | 90 | `combined_celegans.txt` (`celegan_ind_stan.txt` + `CX5461_UVA_c-elegans.SBS96.all`) |
| `unfiltered_chicken_SBS96.txt` | 23 | 307 | 3 | `chicken_ind_stan.txt` |
| `unfiltered_rat_SBS96.txt` | 5 | 307 | 5 | `Samples_Mutational_Spectra_rat.txt` |
| **Total** | **1,482** | | **653** | |

Sources are the files the earlier filtering notebook (`filter_based_on_tmb.ipynb`)
read, copied unchanged; all are background-subtracted. The 21 C. elegans
CX-5461 samples come from a separate file (`CX5461_UVA_c-elegans.SBS96.all`)
and have whole-number counts, unlike the other profiles; 18 of them are below
307 and removed, leaving UVA14, UVA17 and UVA18.

The cutoff is 307 SBSs for every species: the Poisson-resampling stability
threshold, i.e. the SBS count at which 99% of simulations are stable, over all
samples. It is the same threshold as the earlier inputs; the difference is
that every sample is now tested.

The earlier inputs (`filtered_<species>_307.txt`, one cutoff of 307 for all
species) are in git history; the tests check that preprocessing with 307 for
every species reproduces their sample lists, apart from the 18 CX-5461 samples
below 307 that the old notebook let through.

## Required files by mutation type

### SBS — unfiltered counts (one file per species)

```
unfiltered_mouse_SBS96.txt
unfiltered_human_SBS96.txt
unfiltered_celegans_SBS96.txt
unfiltered_chicken_SBS96.txt
unfiltered_rat_SBS96.txt
```

Any file name works as long as it contains the species (and, for the
`per-species` option, has a value in `min_mutations_per_species`). Preprocessing writes the filtered counts and the
normalized profiles to `input_cleaned/SBS/`.

### DBS — raw counts only (normalised internally)

```
filtered_mouse_DBS.txt
filtered_rat_DBS.txt
filtered_chicken_DBS.txt
filtered_celegans_DBS.txt
filtered_human_DBS.txt
```

### ID — raw counts only (normalised internally)

```
filtered_mouse_ID.txt
filtered_rat_ID.txt
filtered_chicken_ID.txt
filtered_celegans_ID.txt
filtered_human_ID.txt
```


## File format

All input count files are tab-separated with:
- Rows = mutational contexts (96 for SBS, 78 for DBS, 83 for ID)
- Columns = sample names
- Values = mutation counts (fractional after background subtraction)

The normalized SBS files written by preprocessing have the same shape, with
each column summing to 1.
